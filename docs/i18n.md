# i18n（控件里的固定文案）

控件里有几处文案是控件自己说的：输入框的「清除」、弹层的「关闭」、密码框的「显示/隐藏密码」。根包内置一张小消息表，按 `c.Locale()` 取，app 可以覆盖。

## 用法

```go
myui.Message(c, "clear")   // 帧的语言里的「清除」
myui.SetMessages("fr", map[string]string{"close": "Fermer"})
```

控件自己用的是这张表：文案跟着 app 的语言走（`mygo.App.SetLocale("zh-Hans")`）。

## 回退链

语言标签逐级回退：`zh-Hans-CN` → `zh-Hans` → `zh` → `en`；表里没有的键返回键名本身。

| 键 | en | zh-Hans | zh-Hant |
|---|---|---|---|
| `clear` | Clear | 清除 | 清除 |
| `close` | Close | 关闭 | 關閉 |
| `showPassword` | Show password | 显示密码 | 顯示密碼 |
| `hidePassword` | Hide password | 隐藏密码 | 隱藏密碼 |

## 已知限制

- 表在包级状态里（`i18n.go` 的 `catalog`），app 在第一帧之前改它；运行中改要自己同步线程。
- 只有控件自己说的文案在表里；app 自己的文案是 app 的事。
- mygo 自己的控件文案（菜单、编辑器）在 mygo 自己的目录里，app 用它自己的目录改（`mygo generate`）。
